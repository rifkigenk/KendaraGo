# Batas wilayah layanan Bali

`bali.geojson` adalah fitur Bali (ID-BA), tanpa penyederhanaan tambahan, dari
[geoBoundaries IDN ADM1, commit 9469f09](https://github.com/wmgeolab/geoBoundaries/blob/9469f09/releaseData/gbOpen/IDN/ADM1/geoBoundaries-IDN-ADM1.geojson).
Boundary ID: IDN-ADM1-65028918; tahun representasi 2017; build 12 Desember 2023.
Sumber data: OpenStreetMap contributors, Wambacher; distribusi geoBoundaries.
Lisensi metadata sumber: [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/),
[atribusi OpenStreetMap](https://www.openstreetmap.org/copyright).

Digunakan sebagai batas operasional layanan (termasuk pulau-pulau Bali), bukan
penetapan batas hukum. Perbarui dataset bila cakupan operasional berubah.
Backend menolak koordinat di luar polygon; tidak bergantung pada label provinsi
dari browser dan tidak memakai kotak pembatas yang mencakup Jawa/Lombok.
